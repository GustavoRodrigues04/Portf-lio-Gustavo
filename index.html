02 / O que eu construí

Projetos

Em produção

Contromega — Site institucional + Painel CRM

Sistema completo para uma empresa de manutenção de portas de aço automáticas que atende São Paulo e todo o Brasil. Desenvolvi sozinho o site público, um painel administrativo com CRM para gestão de clientes e serviços, e a API que conecta tudo. Planejei o projeto em um roadmap de 8 sprints e cuidei da infraestrutura, dos domínios e da segurança das variáveis de ambiente.

  • Site público em Next.js e painel administrativo em React + Vite
  • API REST em Node.js/Express com Prisma ORM
  • Deploy na Vercel (front-ends) e Railway (API), DNS na Cloudflare
  • Relatórios de serviços em Excel gerados com Python (openpyxl)
